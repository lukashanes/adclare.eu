# Security Policy

Adclare handles campaign records, advert assets, public transparency notices and audit history. Please report security issues privately.

## Reporting

Email: `support@adclare.eu`

Include:

- affected version or commit,
- reproduction steps,
- impact,
- suggested fix if known.

Please do not publish details before maintainers have had time to investigate and prepare a fix.

## Supported Versions

Until the first stable release, security fixes target the `main` branch.

## Security Goals

- Tenant and branch isolation.
- Scoped role-based access.
- Stable, unguessable public transparency URLs.
- Protected public forms.
- Private asset storage by default.
- Append-only audit trail for important changes.
- Reliable backup and restore documentation.
